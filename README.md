# PDF 安全遮盖台

一款**纯前端、无需上传文件**的 PDF 遮盖（涂黑）工具。所有解析、编辑、导出均在浏览器本机完成，PDF 不会离开你的电脑。

## 功能

- 导入本地 PDF（文件选择或拖拽入窗口），逐页渲染预览
- 在页面上**绘制、移动、缩放**遮盖框；遮盖框以 PDF 页面坐标保存，缩放、旋转视图、切换页面后位置不漂移
- **文本查找遮盖**：输入一个或多个换行分隔的纯文本词组，在浏览器本地逐页提取文字，
  按页列出命中并在画布高亮，逐项勾选或全选后一次加入遮盖（整批仅一条撤销记录）
- **跨页重复区域**：在当前页框选页眉、页脚等固定区域，输入页码范围（如 `1-3,5`），
  预览各目标页将生成的遮盖框；区域按页面宽高比例映射到不同尺寸页面、越界部分夹取，
  与已有遮盖在 0.01 点容差内相同的框跳过；确认后一次批量加入（整批仅一条撤销记录），
  界面分别列出应用页与跳过页，取消预览不改动任何现有遮盖
- **边缘泄漏检查（导出前核对）**：逐页用 pdf.js 提取文本片段的页面坐标，
  把「与现有遮盖相交、但没被遮盖完整包住」的片段列为风险，按页展示片段摘要与风险数；
  点击结果可跳页并高亮对应遮盖（青色描边）与外露部分（红色块）；
  勾选风险后可批量把关联遮盖扩展到完整包住片段（同一遮盖关联多项时取并集，
  整批修改只产生一条撤销记录）。**没有可提取文字的页面（扫描件 / 图片页）明确列为
  「未检查」，不会当作安全通过**；未经检查或仍有风险时点击导出会先被拦下并提示
- 左侧页面列表显示缩略图与每页遮盖数量，点击快速跳转
- **撤销 / 重做**（Ctrl+Z / Ctrl+Shift+Z 或 Ctrl+Y），Delete 键删除选中框
- **遮盖方案本地导入 / 导出**（JSON）：
  - 加载 PDF 时在浏览器本地计算源文件 **SHA-256**；
  - 「导出方案」下载 JSON，包含格式版本、源文件哈希、页数、各页尺寸及全部页面坐标遮盖框；
  - 「导入方案」先校验结构、哈希、页数、每页尺寸与矩形边界，**任一项不符即拒绝且保持现状**，
    错误提示区分「方案格式损坏」与「方案与当前文档不匹配」；
  - 校验通过后可选择「替换」或「合并」：合并按页及 **0.01 点坐标容差**去重，
    整次导入记为一条撤销记录，可一次 Ctrl+Z 回退；
  - 方案文件只在本机读写，不经过任何服务器
- 安全导出：每页按 **144 DPI** 栅格化，遮盖区域烧入**纯黑**，生成全新 PDF——
  不保留被遮区域的可复制文字，也不保留任何原始页面对象，且各页尺寸与原页一致

## 技术栈

React 18 · TypeScript · Vite · pdfjs-dist（渲染）· pdf-lib（生成 PDF）· Nginx（静态托管）

## 快速开始（Docker，一条命令）

```bash
docker compose up --build
```

启动后访问：**http://localhost:8080**

> 如需更换端口，修改 `docker-compose.yml` 中的 `ports`，如 `"9000:80"`。

## 本地开发

```bash
npm install
npm run dev      # 访问 http://localhost:5173
npm test         # 运行回归测试（文本查找归一化 / 命中几何 / 泄漏几何与扫描）
```

生产构建：`npm run build`，产物在 `dist/`。

## 操作方法

1. **导入**：点击「导入 PDF」或把 PDF 文件拖入窗口。
2. **绘制遮盖**：默认处于「绘制遮盖」模式，在页面上按住鼠标拖出矩形即可。
3. **调整**：切换到「选择 / 调整」模式后，点击选中遮盖框，拖动移动位置，拖动四角/四边手柄缩放；按 Delete 删除选中框，「清空本页」可一次删除当前页全部遮盖。
4. **视图**：工具栏可缩放（50%–300%）、旋转视图（仅影响查看，不影响导出结果）、翻页。
5. **撤销 / 重做**：工具栏按钮或快捷键。
6. **文本查找遮盖**：
   1. 点击工具栏「文本查找遮盖」打开右侧面板；
   2. 在输入框中填写要遮盖的词或短语，**每行一个**；查询词与页面文字中的连续空白
      （包括换行、为排版拉宽的空白）统一按一个空格处理，匹配区分大小写，可跨相邻文字块；
      同一词被 PDF 拆成多个相邻文字块时（同方向、同基线、间距极小且未换行），按连续文本处理，
      整词（如“保密”）也能命中；存在显式空白、换行或排版间距较大时仍按分隔处理；
   3. 点击「查找」后逐页提取文字，面板显示「第 x / N 页」进度，可随时「取消扫描」
      （取消后保留已扫描页面的结果）；
   4. 命中按页分组列出并在当前页画布上高亮（黄色为候选、橙色为已勾选），
      每条只覆盖实际命中的字形范围，**不会遮住同一行中间未命中的间隔文字**；
   5. 勾选单个条目、整页勾选或「全选」，点击「加入遮盖」一次性生成遮盖框——
      整批操作**只产生一条撤销记录**，可一次 Ctrl+Z 全部回退；
   6. 与已有遮盖坐标相同的候选会在重复搜索或应用时自动跳过；
      空词、无匹配、没有可提取文字的页面（如扫描件）均会在面板中给出明确提示；
   7. 点击命中上下文或「第 N 页」可跳转到对应页面核对。
7. **跨页重复区域**（页眉 / 页脚等固定区域批量复制）：
   1. 点击工具栏「跨页重复区域」打开右侧面板（自动切到绘制模式）；
   2. 在**当前页**上按住鼠标框选要重复的区域（如页眉条），面板显示来源页与坐标，
      可点「重新框选」重画；框选只记录区域，不会立即生成遮盖；
   3. 输入目标页码范围，支持 `1-3,5`、倒序 `3-1` 及多种连字符，逗号分隔；
      超出文档页数的页码 / 范围段自动忽略，无法解析时给出错误提示；
   4. 点击「预览」：区域以占源页宽 / 高的**比例**映射到各目标页（适配横版 / 不同尺寸页），
      映射后越出页面的部分**夹取**到页边界内，完全落在页外（夹取后退化为空）的页不生成框；
      画布上蓝色虚线为将加入的框、黄色虚线为将跳过的框、紫色点划线为来源区域，
      点击页码胶囊可跳转各目标页核对；
   5. 与目标页已有遮盖四个坐标差值均在 **0.01 点容差内**相同的页自动标记为跳过；
   6. 面板分别汇总**应用页**与**跳过页**；点击「确认加入」一次批量生成——
      整批**只产生一条撤销记录**，Ctrl+Z 即可整体回退；
   7. 点击「取消预览」、关闭面板或调整来源 / 范围均**不会修改任何现有遮盖**。
8. **遮盖方案导入 / 导出**：
   1. 点击「导出方案」下载 `原文件名_遮盖方案.json`，内含格式版本、源文件 SHA-256、
      页数、各页尺寸（点）与全部遮盖框的 PDF 页面坐标；
   2. 在同一份 PDF 上点击「导入方案」并选择该 JSON：工具先做结构校验
      （JSON 语法、字段、矩形合法性），再核对源文件哈希、页数、每页尺寸与矩形边界，
      任一不符即拒绝并保持现状——提示为红色错误条，**「方案格式损坏」与
      「方案与当前文档不匹配」是两类不同错误**；
   3. 全部校验通过后弹出选择：**替换**（以方案覆盖当前遮盖）或**合并**
      （保留现有遮盖并追加，按页及 0.01 点坐标容差去重）；
   4. 整次导入只有**一条撤销记录**，Ctrl+Z 即可整体回退；取消弹窗则不做任何改动。
9. **边缘泄漏检查（导出前建议执行）**：
   1. 点击工具栏「边缘泄漏检查」打开右侧面板，点击「开始检查」，工具逐页提取文字
      （显示「第 x / N 页」进度），可随时「取消扫描」（取消后保留已扫描页面的结果）；
   2. 检查以 pdf.js 文本项为片段粒度，片段的页面坐标与「文本查找遮盖」使用同一几何模型；
      与遮盖**完全不相交**的文字不在检查范围（本就不打算遮住）；与遮盖相交且被完整包住
      的片段视为安全；**相交却仍有部分露在遮盖外的片段列为风险**（多个遮盖拼合能完整
      包住的不算风险）；
   3. 结果按页分组，标题显示每页风险数；点击「第 N 页」跳页，点击片段摘要则跳页并
      在画布上高亮：青色描边为关联遮盖、青色外框为片段范围、红色实心块为**外露部分**，
      同时自动切到「选择 / 调整」模式并选中关联遮盖；
   4. 勾选单个条目、整页勾选或「全选」，点击「扩展遮盖」：每个关联遮盖被扩展到
      完整包住其全部勾选片段（外扩 1 点余量并夹在页面内），**同一遮盖关联多项时
      取并集、只扩一次**，整批修改**只产生一条撤销记录**，Ctrl+Z 可整体回退；
      处理后结果自动重新核对，已消除的风险从列表移除；
   5. **没有可提取文字的页面（扫描件 / 图片页）、未扫描到的页面、提取失败的页面
      统一列在「未检查页面」中——未检查不等于安全**，这类页面请人工目检；
   6. 遮盖被手工修改、撤销或导入方案后，已打开的检查结果会自动按新遮盖重新核对；
      扫描不完整或结果过期时，面板会提示重新检查；
   7. 尚未运行检查、检查仍有风险或仍有未检查页时，点击「导出安全 PDF」会先被拦下：
      面板自动打开并说明原因，确认人工核对无误后**再次点击**导出即可。
10. **导出**：点击「导出安全 PDF」，逐页栅格化并烧入遮盖后，自动下载 `原文件名_已遮盖.pdf`。

## 安全说明

- 源文件通过 `FileReader` 读入浏览器内存，文本查找与边缘泄漏检查同样仅在本机调用
  pdf.js 解析，全程无网络请求，不上传任何数据。
- 源文件 SHA-256 与方案 JSON 的生成、校验均在浏览器本地完成
  （优先使用 Web Crypto，非安全上下文下回退内置纯 JS SHA-256 实现，依然无网络请求）；
  方案文件不会上传，只通过浏览器下载 / 本地选择读取。
- 导出的 PDF 每页只是一张 144 DPI 的位图：原文字层、矢量图形、注释、元数据均不会进入新文件，被遮盖的内容无法通过复制、搜索或删除遮盖层恢复。
